# Project ShadowWatcher

**CHIRASU Threat Intelligence and Autonomous Analysis System**

------------------------------------------------------------------------

## Overview

Project ShadowWatcher is a distributed, autonomous cybersecurity
intelligence and analysis system designed to monitor global threat feeds
and evaluate their relevance to the CHIRASU infrastructure.

It consists of two independent but coordinated operatives:

-   **Rena (CobraShadow)** --- Threat acquisition and structured
    intelligence generation
-   **Astrae (CobraIsolation)** --- Autonomous threat analysis and
    infrastructure-specific risk assessment

ShadowWatcher continuously monitors vulnerability feeds, collects threat
intelligence, and produces contextual risk assessments tailored
specifically to CHIRASU's operational environment.

Once deployed, ShadowWatcher operates fully autonomously.

## Core Operatives

### Rena --- Threat Acquisition Operative

**File:** `renabot.py`

Rena functions as the threat acquisition node. She retrieves
vulnerability intelligence from external sources and converts it into
structured threat cards.

#### Responsibilities

-   Retrieve CVEs from NVD API
-   Monitor CISA Known Exploited Vulnerabilities feed
-   Collect intelligence from cybersecurity RSS feeds
-   Filter and normalize vulnerability data
-   Generate structured threat card embeds
-   Publish threat intelligence to Discord channel
-   Execute scheduled threat pulse reporting
-   Maintain threat intelligence logs

------------------------------------------------------------------------

### Astrae --- Autonomous Threat Analysis Operative

**File:** `astrae_bot.py`

Astrae functions as the threat analysis node. She consumes threat cards
generated by Rena and evaluates their operational relevance to CHIRASU
infrastructure.

#### Responsibilities

-   Monitor threat card channel continuously
-   Parse CVE identifiers and vulnerability metadata
-   Retrieve extended vulnerability data from NVD
-   Perform infrastructure-aware risk analysis
-   Evaluate exploitability within CHIRASU environment
-   Generate structured threat assessment reports
-   Publish analysis output

------------------------------------------------------------------------
